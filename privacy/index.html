Política de Privacidad

Práctica Mail Watcher — herramienta personal

Práctica Mail Watcher es una herramienta de uso estrictamente personal, operada por un único usuario para monitorear su propia cuenta de Gmail. No es un servicio público, no tiene usuarios externos y no procesa datos de terceros.

Qué datos de Google se acceden

Únicamente, de los correos de la propia bandeja del usuario: remitente, asunto, un fragmento corto de vista previa ("snippet") e identificadores internos del mensaje (message ID, thread ID). El cuerpo completo del correo nunca se descarga ni se lee.

Finalidad del acceso

Detectar automáticamente correos relacionados con postulaciones a prácticas profesionales y procesos de selección laboral, y clasificarlos (por ejemplo: confirmación de postulación, entrevista, evaluación, avance de proceso, oferta, rechazo) para generar una notificación local al usuario.

Alcance del acceso: solo lectura

El acceso usa exclusivamente el scope https://www.googleapis.com/auth/gmail.readonly de la API de Gmail. La aplicación:

  • Nunca envía correos.
  • Nunca modifica, etiqueta ni mueve correos.
  • Nunca elimina correos.
  • Nunca responde en nombre del usuario.

Qué datos se almacenan, y dónde

Toda la información se almacena únicamente de forma local, en el propio computador del usuario, en una base de datos SQLite local. Se guarda: el ID del mensaje y del hilo (para evitar notificaciones duplicadas), remitente, asunto, categoría y prioridad asignadas, y si se notificó o no. El cuerpo completo del correo nunca se almacena. Nada de esto se sube a ningún servidor, nube o servicio externo.

Credenciales y tokens

El token de acceso OAuth se guarda únicamente en el disco local del usuario y nunca se comparte, transmite ni sube a ningún repositorio o servicio de terceros.

Venta o compartición de datos

Los datos no se venden, no se comparten con terceros y no se usan con fines publicitarios ni de analítica.

Cómo revocar el acceso

El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions, eliminando el acceso otorgado a esta aplicación. Esto invalida el acceso de inmediato.

Uso estrictamente personal

Esta aplicación fue creada por y para un único usuario, para monitorear su propia cuenta de Gmail. No está diseñada ni ofrecida como servicio para terceros.

Contacto

Para cualquier consulta sobre esta herramienta o esta política, contactar al propietario de la cuenta de Gmail monitoreada.
